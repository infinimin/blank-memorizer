# 🤝 Contributing / 기여 가이드

## 한국어

기여를 환영합니다! 아래 가이드라인을 따라주세요.

### 기여 방법

1. 이 저장소를 **Fork** 합니다
2. 새 브랜치를 생성합니다 (`git checkout -b feature/amazing-feature`)
3. 변경 사항을 커밋합니다 (`git commit -m 'Add amazing feature'`)
4. 브랜치에 푸시합니다 (`git push origin feature/amazing-feature`)
5. **Pull Request**를 생성합니다

### 가이드라인

- 이 프로젝트는 **순수 HTML/CSS/JS**로 유지됩니다 (프레임워크 사용 금지)
- 모든 기능은 **단일 HTML 파일** 안에서 동작해야 합니다
- **오프라인 동작**을 보장해야 합니다 (외부 API 호출 금지)
- 한국어/영어 모두 사용할 수 있어야 합니다

### 소스 파일 기여

`sources/` 폴더에 학습 자료를 추가할 때:
- **반드시 본인이 저작권을 가진 콘텐츠**만 업로드하세요
- Markdown 형식으로 `## 제목`으로 주제를 구분하세요
- `sources/index.json`에 파일을 등록하세요

## English

Contributions are welcome! Please follow the guidelines below.

### How to Contribute

1. **Fork** this repository
2. Create a new branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Create a **Pull Request**

### Guidelines

- This project uses **vanilla HTML/CSS/JS only** (no frameworks)
- All features must work within a **single HTML file**
- Must work **fully offline** (no external API calls)
- Content should be accessible in both Korean and English

### Source File Contributions

When adding study materials to `sources/`:
- Only upload **content you own the copyright to**
- Use Markdown format with `## Heading` to separate topics
- Register files in `sources/index.json`
